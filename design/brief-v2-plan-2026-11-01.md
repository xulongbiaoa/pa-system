# AI 参谋简报改进方案（Claude 出案，2026-11-01）

来源：用户点名让外部 Claude 出方案、助理实施。Claude 基于真实病样本（逐座缺口枚举的主推演、六条同款证据、流水账研判）与系统约束（包内事实、主备+接管哲学、15 分钟一轮）给出。助理对账意见见文末。

## 总原则

把简报从「账本状态的逐项播报」改成「当前论点 → 本轮变化 → 变化意味着什么 → 下一步看什么 → 什么条件下换剧本」。缺口账本仍是唯一事实中枢，但简报不再按缺口逐座朗读，而是按"论点"组织缺口。

每轮简报固定回答五个问题：①现在谁占主动？②为什么？③本轮发生了什么变化？④接下来只看什么？⑤什么事实出现后主剧本失效、备剧本接管？

## 1. 目标信息结构（六块，顺序固定）

**A. 一句话结论**：stance.side（bullish/bearish/balanced/insufficient）、stance.control（主动进攻/防守占优/争夺中/信息不足）、stance.status（确认/维持/受挑战/已失效）、stance.summary（≤60 字）。例：「多方仍是防守占优，但尚未形成向上突破；最近支撑测试尚未决出结果。」——"防守占优"比"主动权未失"准确，样本没有主动扩张的事实。

**B. 主推演**：必须是剧本句不是状态句，含三元素：价格正在做什么、哪些账本事实支持、目前处于什么阶段（phase：等待确认/正在展开/被挑战/接近失效）。证据改为 claims 对象：{claim（支持哪个判断）, weight（核心/辅助/背景）, fact, refs}；页面默认只展开 2 条核心 + 最多 1 条辅助，其余进账本详情。

**C. 反证与风险**：分 unresolved（尚未解决的关键争议）与 adverse（不利但未足以接管）两类，每条带 effect 说明它如何限制当前判断。反证必须是"会改变判断的事实"，不是所有没支持主推演的数字。

**D. 本轮更新**：delta.kind 枚举（no_material_change/strengthened/weakened/new_branch/invalidated）+ 三段强制：what_changed（带引用）、what_it_means、effect_on_hypothesis。安静轮标准写法：「本轮无改变主推演的增量。新增事实：78,068.00 被确认。含义：与 77,897.03 的测试没有账本关联。结论：主推演维持，接管条件不变。」——无实质变化是有效简报，不是空白。

**E. 接管条件（新增独立块，始终显示）**：handoff{from,to,trigger,trigger_refs,not_triggered_by[],status}。例：trigger=「77,897.03 的向上缺口被触线并关账」；not_triggered_by=「仅开始回补测试/测试尚未结束/无关位置的确认事件」。解决"测试开始≠接管"的误读。

**F. 观察计划**：保留四段链（观察位置→等待行为→复核触发→取消条件），加 hypothesis_id 与 refs 绑定，页面明示"这张计划在验证主推演还是等待接管"。候选/订单触发移出简报主区（提案区独立），避免影子分析看起来像交易指令。

## 2. 判读员推理规程（六步）

1. **先恢复上一轮论点**：读主/备推演、接管条件、观察计划；默认动作是维持/加强/削弱/受挑战/失效，只有新分支或失效才立新论。
2. **只筛与主张有关的增量**：增量先归类 A 改变主推演状态 / B 改变接管距离 / C 改变观察计划 / D 只是账本记录；只有 A/B/C 进简报主文，D 一句带过。
3. **先更新论点再组织证据**：事实变化→对已有论点的影响→主推演状态→备/接管是否变化→计划是否变化。内部先做"论点更新表"（上轮状态/本轮事实/本轮影响/新状态），不必全展示。
4. **缺口按结构角色聚合**：nearest_defense（最近防线）/ reinforcing_defenses（后续防线）/ unresolved_resistance（上方未决阻力）/ handoff_level（接管线）；同一缺口只出现在一个角色里。样本六座 → 四个角色：77,897.03 最近防线、77,764.01 辅助防线、77,188.51 背景防线、78,297.05 上方未决阻力。
5. **显式判断本轮是否改变主备关系**：变强？变弱？备是否更接近接管？接管条件是否改变？四项皆无 → delta.kind=no_material_change，沿用上轮主推演原文，不重写全局总结。
6. **最后才生成文字**：顺序 = 结论→主推演→≤3 组证据→1 条反证/未决→本轮更新→接管条件→观察计划。

语义禁区表（不得混用）：测试开始≠支撑守住；测试进行中≠已确认；尚未测试≠已证明有效；被拒≠已经向目标方向展开；触线≠必然反转；无关联确认≠剧本发生变化。

## 3. 示范改写（只用样本事实）

- 一句话结论：「多方仍防守占优，但尚未形成向上突破；最近支撑正在接受测试，结果尚未决定。」
- 主推演：「价格仍处在下方支撑结构的防守阶段，当前更像支撑带内整理，而不是已经启动的上攻。最近的 77,897.03 向上缺口第 1 次回补测试正在进行但尚未触线关账；更下方的支撑没有出现新的失守事实，其中 77,764.01 曾被拒，77,188.51 已连续两次被拒。」（不再逐一列 77,862.15/77,866.01/77,796.01 的"尚未测试"——它们同属一个结构事实：更下方仍有未被击穿的支撑层，但尚未测试不等于已经证明支撑有效。）
- 核心证据：「最近防线尚未失守——77,897.03 向上缺口仍开放，第 1 次回补测试正在进行，尚未触线关账。」辅助：「下方曾出现防守——77,764.01 测试被拒收官；77,188.51 前两次均被拒。」未决阻力：「现价仍在 78,297.05 下方——多方尚未处理上方阻力，结论只能是防守占优，不能升级为主动上攻。」
- 未决点：「77,897.03 第 1 次测试仍在进行——'支撑守住'尚未完成确认；若最终触线关账，主推演需失效或降级。」
- 本轮研判：「本轮没有改变主推演的实质增量。新增事实是 14:45 确认 78,068.00；该确认与 77,897.03 的第 1 次测试没有账本关联，因此没有改变最近支撑测试的状态，也没有让备推演提前接管。结论：主推演维持。」
- 接管条件：「主推演失效/备推演接管：77,897.03 向上缺口被触线并关账。仅开始回补测试、测试仍在进行、或无关联确认，均不构成接管。」

## 4. 落地切分

**只改提示词/规程**：结构角色聚合（主推演最多点名 3 座）、增量先归类、no_material_change 复用上轮论点、文本上限（一句话 ≤60 字、主推演 ≤100 字、核心证据 ≤2、辅助 ≤1、反证 ≤2、本轮研判 ≤100 字）、语义禁区表。

**改 schema（brain-output/v2）**：假设加 role（primary/backup）与 phase；证据改 claims 对象（claim/effect/weight/fact/refs）；新增 delta 对象；新增 handoff 对象并契约校验（双方假设存在、trigger 引用可核验、不许只存在于自由文本）；history reason 结构化（changed_refs/old_state/new_state/why，自由文本保留供展示）；引用带类型（gap/test/event/level/bar）防"引用对了却说错事实"。

**页面渲染**：顶部固定结论条；证据改分组卡片（判断/事实/作用），距离现价退回账本详情不做主叙事；反证与未决分开（未决不用红色满格）；本轮变化固定位置（有变化写变化、无变化明写"本轮无实质变化"）；接管条件高亮固定显示；观察计划标注服务于哪个推演；页面不再靠文本猜主备，只认 schema role。

## 5. 验收标准（可操作）

- 结构完整性：七项缺一不合格（结论/剧本式主推演/≥1 核心证据/≥1 未决或反证/明确本轮是否改变判断/明确接管条件/四段计划）。
- 反枚举：主推演点名缺口 ≤3 座；同一缺口全简报重复朗读 ≤2 次；连续 ≥3 句不同句式；删掉一半数字逻辑无损失 = 数字过多。
- 论点—证据：每条证据能说清支持/削弱/限制哪个论点；无"引用存在但结论超事实"；无语义禁区违规。
- 增量推理：每轮必答"发生了什么→与哪个论点有关→变强/变弱/不变→是否改变接管距离"；只有事实句没有结论变化 = 流水账。
- 安静轮：无新缺口/关账时能输出"无实质变化"、不新增假设、不重写全局盘点、接管与计划保持稳定。
- 接管演练五例：测试开始（不接管）/被拒（增强主推演不宣称趋势展开）/触线关账（接管）/无关联确认（不改变）/上方阻力未测（限制结论强度）。
- 30 秒阅读测试：不看账本的读者 30 秒内答对五问（谁占主动/主推演是什么/最近发生了什么/下一步看什么/什么情况换剧本）；正文总量目标 350–450 汉字。

## 6. 实施顺序（Claude 建议）

一阶段：改规程与提示词（角色聚合、delta 三段、接管单列、no_material_change）+ 历史快照回放验证稳定性。二阶段：schema v2 + 校验。三阶段：renderBrief 按六块重做。四阶段：回放验收（新缺口/测试开始/被拒/触线关账/无关确认/无变化六类轮次）。
