# B3 突破失败翻面（v2 四分稿 · 样板，待用户过目）

出处：骨架 v1 突破事件族（原 A5 反手面）；本地两笔大胜单出自此面
（+452.85 / +155.73，样本不足，只作倾向）。
四分口径（全卡通用）：必须有 = 缺一即不合格、写进 pending 必须引
条目号；加分项 = 只影响评级与排序，**不许列为 missing**；否决项 =
出现即不合格；封顶条款 = 必须项齐 + 无否决，必须写候选。

## 必须有

- **B3-N1 语境**：突破已发生（区间沿口或决胜点被破），且当前处于
  回收窗口第 1–3 根内——失败只在这个窗口里裁定。
- **B3-N2 位置**：入场位 = 翻面位（被破的沿口线）；价格回到翻面位
  接受测试，候选必须点名该位所在决胜点。
- **B3-N3 触发事件**：窗口内出现一根**收盘收回位内**的 K 线——
  这是失败裁定成立的那一根，也是入场决策根。
- **B3-N4 触发根地板**：收回根须有方向实体（不是十字星、不是纯
  影线收回）。只设这条定性地板，**不设**实体占比 / CLV 数值高线
  （数值高线归加分 B3-B3）。

## 加分项（不许列为 missing）

- **B3-B1 反向跟进**：收回根之后一根同向延续。〔提议由原卡必要
  条件降为加分：跟进发生在收回之后，设为必要等于结构性晚一根；
  解剖中它与「缺收回」并列第一大缺项。降级后产出变化由错误空仓
  考试与影子样本验收，不凭感觉。〕
- **B3-B2 第一次回踩**：翻面位第一次被回踩测试（原卡「优先审」
  本就是评级语义）。
- **B3-B3 成色高线**：收回根实体饱满、CLV 靠向翻面方向极值。
- **B3-B4 库存叠加**：突破腿越长、翻面位处缺口账本套住的人越多
  （被套突破方是翻面燃料）。
- **B3-B5（负加分 · 降格）**：收回根盘中创反向新极值——收回的
  成色打折、评级降一档，但不否决。〔提议维持原卡「降格审」，不
  升为否决：刺穿后收回本身仍可能是夺回，升否决会误杀。〕

## 否决项

- **B3-V1 窗口走满未收回**：第 3 根收盘仍在位外 → 失败不成立，
  本事件内不得再以 B3 审（要审等下一个事件/决胜点）。
- **B3-V2 抢跑**：窗口第一根的回调属突破方回踩，不算失败——
  第一根就翻面 = 抢跑，定义性否决。
- **B3-V3 战役作废**：本地图 campaign_void_if 已发生（如 MM 已达
  且顺势分支按条款关闭、起点失效），B3 随地图一并关闭。

## 封顶条款

N1–N4 全齐且无 V 项 → **必须**写候选并标 qualified。跟进
（B1）、成色高线（B3）、第二腿形态、三推齐整等一律不得再列为
missing；判读员坚持引用时 basis 必须标 `extra`，且 extra 不许
单独构成不写候选的理由（纲领 Build 1）。

## 止损 / 目标 / 失效（照原卡）

- 止损：突破腿极值外侧 + 缓冲。
- 目标序列：原区间 / 原结构对侧边缘 → 更深 MM，按序列逐级算
  净 RR（RR 数值归 gate，卡只管序列存在性）。
- 失效：入场后价格再收回突破方向位外 → 前提破，市价出。

## 常见误判（映射到四分）

① 窗口没走满就抢翻面 → V2 / N1；② 目标只取近目标丢序列 →
计划问题、归 gate，不进 missing；③ 等跟进等到位置已晚 →
B1 已降加分，封顶条款禁止以此挂起。
