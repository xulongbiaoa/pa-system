# A2 M2S（顺势二次入场 · 空）（四分版 2026-10-31）

出处：Brooks V12/V9（L2 的 EMA 变体，手册 setup #10 镜像）；Brooks 十大第 4 位 H2/L2。
四分口径（全卡通用）：必须有 = 缺一即不合格、写进 pending 必须引
条目号；加分项 = 只影响评级与排序，**不许列为 missing**；否决项 =
出现即不合格；封顶条款 = 必须项齐 + 无否决，必须写候选。

## 必须有

- **A2-N1 语境**：下降趋势。
- **A2-N2 双前置一**：趋势 MM 未达（双前置缺一不可）；目标
  序列的空间存在性属本条，净 RR 数字归 gate 执法，不许以
  「RR 还没细算」挂起。
- **A2-N3 双前置二**：反弹已走出第二腿（腿数由特征包计）。
- **A2-N4 位置**：反弹落点在 EMA 一带 / 前跌破位 / 要塞下沿翻面
  位之一，且在决胜点测试区内。
- **A2-N5 触发**：合格级信号 K——顺向（阴）实体收盘、信号 K
  大半截不在 EMA 错侧、无盘中反向新极值（不创新高）。
  〔归类注：三项都是信号 K 本根的成色构成、与入场事件同根发生，
  且原卡以「不合格」定义错侧一项，故整组归必须；按合格级审，
  不用突破级强信号标准。〕

## 加分项（不许列为 missing）

- **A2-B1 突破级强度**：信号 K 强于合格级（达突破级）。〔归类
  注：原卡明言不用突破级强信号标准审本卡，即合格级已足；超出
  合格级的强度只是更漂亮，归加分。〕

## 否决项

- **A2-V1 逆势单**：下降趋势里在支撑位抢多等逆势单不走本卡。
- **A2-V2 起点失效**：收盘破趋势起点 → 顺势面全关。

## 封顶条款

N1–N5 全齐且无 V 项 → **必须**写候选并标 qualified。突破级
强信号（B1）、第三腿、更饱满的实体等一律不得再列为 missing；
判读员坚持引用时 basis 必须标 `extra`，且 extra 不许单独构成
不写候选的理由（纲领 Build 1）。

## 止损 / 目标 / 失效

- 止损：第二腿高点外侧 + 缓冲。
- 目标序列：最小目标（反弹前低）→ 本腿 MM → 下一完好要塞。
- 失效与降级：反弹收复逾 50% 降级为观察；收盘破趋势起点 →
  顺势面全关（即 A2-V2）。

## 常见误判（映射到四分）

① 把第一腿当第二腿 → N3；② 下降趋势里在支撑位抢多（逆势单
不走本卡）→ V1；③ 信号 K 大半截在 EMA 错侧仍判合格 → N5。
