## 宪法：四条不许单点 + 两条总纲

1. **目标是序列**：最小目标（趋势腿前极值）→ 本腿 MM → 下一要塞，逐级算 RR；升级须写 (a) 两级间无完好要塞封顶 (b) 结构理由。哨位（只形成过一次、从未被回测的摆动极值）不作目标、不封顶。突破开天窗 = 用本 setup 自带 MM 当目标。区间语境按最近完好位面值计价。
2. **信号是系列**：形态只判本根有没有触发。不合格 = 候选挂起、候下一根，审计书写明重新合格条件——永不作终局判决。二次入场类按「合格」级审（顺向实体收盘、无盘中反向新极值），不用突破级强信号标准。
3. **方向是双绊线**：board 预写的翻面条件触发即翻面——旧方向菜单关闭（再做走 D 分支全新全审），新方向对翻面位的第一次回踩优先审计；触发时不许换更严的尺。突破失败须走满回收窗口（1–3 根），窗口内第一根回调属于突破方，不是失败。
4. **背景是假设集**：2–3 个假设常驻——一个主假设 + 若干备选，每个带定性、成立/作废条件、对应剧本；备选写明**接管条件**（什么事实出现就升为主）。**不记数字权重**：证据搬动的是谁主谁备，易主是带触发事实的事件、留笔记。背景每审按当下结构重判。趋势起点 = 趋势起点 K，必须落在真正发动处（基底/突破点），不是数据窗口边界；定性变了，锚随之重定位。回吐 ≥50% 判弱，收盘破起点判死。
5. **不清楚不做**：成色含糊的位置/信号/背景，一律不做，不打折放行。
6. **纪律先于盈亏**：判卷只看纪律合规；亏损不自动触发总结加规，改规只由用户裁定。**允许亏，但要亏得有逻辑**（2026-10-30 用户补正）：入场前逻辑链完整、四关诚实通过的单子，**亏了也是好单**——判卷按「好单」记，盈亏只记账、不记功过；逻辑有一环是事后补的、跳关的、或前提已破还硬扛的单子，**赢了也是坏单**。好坏与盈亏是两个轴，分开记。四关验的是单子的逻辑成不成立，不是这笔会不会亏——逻辑齐了就下单，不许因为怕亏把关卡偷偷收紧。

## 流程（预演制：决策不在 K 里，2026-10-30 用户定）

**思考全部发生在价格到达之前，K 线只负责触发；只看关键地方的 K。**

1. **画地图**：L0 记账（缺口账本：敞开缺口、套住谁、套深/套时/未遂、双方解套位）+ 关键位 + 趋势起点与 MM 状态（第 0 查）。标出本段的**决胜点**——**决胜点就是预画的支撑/阻力（要塞级）**：涨，考的是上方最近阻力；跌，考的是下方最近支撑；两位之间是赶路，不设考场。保证有考试，不保证考过——停住走守住分支、冲过去走破位分支，所以每点必须双分支。
2. **在每个决胜点预写计划**：剧本成对（守住 → 动作 A；破了奔更深 MM → 动作 B），每支写全：订单（类型 / 价格 / 名义口径）、触发判词、作废条件、成交后的 TP/SL 与前提。**触发判词用核心菜单的 setup 写明**——这个点上以什么形态入场（如该位回踩的第二腿 H2、回收窗口裁定后的翻面、MTR 三件套），提前点名，不许到点现找。**四关在写计划时过完**（背景第 0 查 → 位置 → 形态标准 → RR）。计划写不出逻辑的决胜点 = 提前划掉，不做。每个假设至少挂一支剧本——没写应对的情景不上板。
3. **逐根推进 = 核对，不是思考**：未进入任何决胜点的测试区 = 直接过，不分析、不审计、不调 facts。**只有价格进入决胜点测试区时，才调 facts、才逐根盯到达行为。**
4. **到达 = 核对清单**：到点没？该支预定的 setup 触发了没（形态与成色按预写标准验）？前提还在没？三项齐 → 照单执行；没触发 = 该支作废，等下一支或下一个决胜点——**不临场改写计划、不现场升格**。setup 只在决胜点上存在：不在地图点位上出现的形态，不构成入场理由。
5. **滚动预演**：一段计划走完、或段内变故作废 → 只重写**段计划**（回第 1 步，但只动段层，见下「两层计划」）。价格到达没预演过的点 = 不做，记为计划缺口（判卷用）。

## 两层计划（大结构防切碎，2026-10-30 第 3 局判卷后定）

计划分两层，**段层永远不许动战役层**：

- **战役层（局首画、全程冻结）**：市场定性、当前趋势的**起点与起点腿 MM**（第 0 查的读数）、要塞梯队、主假设 + 备选与接管条件。这一层就是「大结构」。
- **段层（滚动重写）**：只能从战役图上选接下来武装哪几个决胜点、给它们写分支；**不许重锚起点、不许用局部腿重算 MM、不许移动或重评战役要塞、不许换主假设**（换主假设只能由战役层预写的接管条件触发）。
- **战役图只在战役事件时重画**：起点失效（收盘破起点 / 回吐裁决触发）、起点腿 MM 到达、预写接管条件打印、定性本身翻面（趋势↔区间证据成立）。接管条件触发 = 先重画战役图，再在新图下写段计划，不许拿旧段计划续命。
- **可审计口径**：每段看板 ctx 里的战役行（起点 / MM 目标 / MM 状态 / 主假设）须与上一段逐字一致，除非当段笔记引用了一条战役事件。判卷按此条查切碎。

## 四关（顺序不换；写计划时过，到达时不再重过）

背景（**第 0 查：当前趋势的 MM 到没到** → 主假设对位？逆势方目标审计完了？）→ 位置（要塞 / 翻面位 / 区间边缘 / EMA；查踩踏史：收盘穿 ≥3 次降级、到达 ≥4 次衰减）→ 形态（触发成色；大信号先过滤，过大信号只作语境）→ RR（净口径，只否决、不批准）。

**MM 到位口径**：量的是当前趋势从**趋势起点那条腿**投影的 MM（单腿口径，不换锚）。未达 = 磁吸还没兑现：回踩默认顺势、逆势尝试默认是旗。已达 = 趋势标**成熟**：顺势剧本关闭（回报端已被目标吃掉）、翻面与 MTR 剧本升为接管候选。到达只改姿势、不判死刑——趋势失效仍按裁决线（回吐 ≥50% 降级、收破起点失效）。

## 硬数字

- 单笔风险 100（1%）；名义按当前现金倒算封顶（限价 ÷1.0002、市价 ÷1.0005）。
- 净 RR < 1.5 否决；1.5–1.65 边际带从严：弱腿 / 无主导假设 / 踩踏区，任一即否。
- 费用：入场市价 0.05% / 限价 0.02%，出场一律 0.05%。
- 止损放结构外 + 缓冲，不压整数位与摆动极值。
- Bar 140 后不开新仓。
- 前提破（收盘越过前提线）即市价出场，不等止损、不躲止损。

## 入场纪律

- 趋势/突破：突破当根不开仓（只定方向与锚）；顺势入场只走 H2/L2——信号确认收盘市价进，或按剧本在回踩位限价预埋，二者只选其一并写进剧本。禁止向确认反方向挂便宜限价等回踩。
- 区间边缘 / 翻面回踩位：可限价预挂；翻面位第一次回踩优先审。
- 成交偏差 >25% 复核前提，>50% 计划作废。

## Setup 核心清单：三族（2026-10-30 用户拍板）

1. **突破事件**（三面都是它）：
   - **顺势突破（只定方向，不直接入场）**：强突破（大实体收在位外 + 跟进；尖峰也是强突破）确认的是方向、趋势起点与 MM 锚——**当根不开仓**；顺势入场只走第 2 族。语境门：**交易区间里的突破默认先按假的审**（Brooks：区间突破约 80% 失败）。
   - **突破回踩**：突破成立后回踩突破点/翻面位——回踩本身构成第二腿时并入第 2 族按 H2 审；不呈第二腿形态的第一触碰不入场。
   - **突破失败翻面**：回收窗口（1–3 根）裁定突破失败 → 在翻面位做失败方（原 A5 的反手面；全批两笔大胜单 +452.85 / +155.73 都是这一面）。
2. **M2B / M2S 顺势二次入场——顺势唯一的入场形态**（Brooks 十大第 4 位 H2/L2 的 EMA 版；2026-10-30 用户收紧：顺势追只能是「MM 盈亏比合适 + H2 入场」）：双前置缺一不可——① **当前趋势 MM 未达**、按目标序列算净 RR 达标（已达 MM 则顺势全关，与背景第 0 查咬合）；② 回踩走出第二腿、第二次尝试，触发标准 = 合格级（顺向实体收盘、无盘中反向新极值），不许用突破级标准毙。前提 = 回踩破趋势裁决线（起点回吐 ≥50% 先降级、收破起点即停）。
3. **MTR 主要趋势反转**（Brooks 十大第 1 位，但他自标波段胜率只有约 40%——靠 RR 不靠胜率）：门最严——仅老趋势 + 两腿衰竭尝试 + TBTL 满足才开审，全新全审；无三件套不开单，宁可错过。

**观察 · 不执行**（降附册）：区间边缘剥头皮（C 类）、楔形猜顶底、高潮后首回、其余反转杂项。
**复牌条件**：核心三族攒够 **20 笔计分样本** 后，再议观察项是否放回。
出场纪律不变：MM/目标到达 = 出场分支，先于一切新开仓想法；前提破即出。
