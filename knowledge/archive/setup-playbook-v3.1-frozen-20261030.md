## 底层 · 判断辅助（计数与量法）

> 树上每一条 if 都要调用这里的一把尺。尺没有定义，if 就是假的——审不出真假。
> 本层只产出读数，不产出交易；读数喂给 L0/L1/L1.5 与各分支的识别条件。

| 辅助 | 定义（Brooks 口径 + 本体系已定规则） | 读数喂给谁 |
|---|---|---|
| **数腿** | 一段同向推进为一条腿，以反向摆动点为界；**清一色同向 K（无反向摆动点）永远只是一条腿**，不许在腿内部切分、不借小级别摆动点凑腿 | M2B/H2 的「两腿」、ABC 的三段、尖峰腿、MM 的单腿口径 |
| **数 H / L** | 牛市回调中，高点越过前根高点的第一根 K = H1；失败并创新低后，再次出现 = H2；熊市镜像为 L1/L2。**没有新的回调极值（新低点/新手高点），第二次上攻不算 H2**——只是 H1 的延续（v2.1 补，源自第九局歧义 3、4）。数到 H3/H4 还在磨 = 回调变质，按区间处理 | A1/A2/B1/B2 的触发计数；分支 A→C 的降级开关 |
| **摆动结构** | HH+HL = 上升结构；LH+LL = 下降结构；摆动极值被实体收破 = 结构第一道裂缝（先数腿、看跟进，不许单根小 K 定翻转） | L1 语境路由的总开关；活地图的改线触发 |
| **嵌套级别** | 本级别的一根 K，内部是小级别的一整段趋势；本级别的一段回调腿，内部自带腿数、尝试与它自己的反转可能（v2.2 补，用户 2026-10-29 点名） | 全部读图动作的前提，见下方专条 |
| **尝试计数** | 同一位置被到达的次数与每次的结局（守住/收破/假破收回）；**「穿越」以收盘价穿过计**——盘中刺穿收回只记一次到达、不记穿越（v2.1 补，源自第九局歧义 7）。**区域型要塞的穿越以区域远边为准**：收盘落在区域内不算穿越、也不算守住，只算一次到达（v2.3 补，源自第十局歧义 3）。**区域的边 = 形成该区的那簇摆动点的极值**（最高的高点/最低的低点），不是目测中线；**收盘恰压在线上 = 到达**，不算穿越也不算守住（v2.4 补，源自第十一局歧义 1/8） | 先验「第二次尝试」行；踩踏降级（收盘穿越 ≥3 次 → 中线）；城池评级（守军库存厚度） |
| **回调深度比** | 回调深度 ÷ 前进腿长度：浅（<38%）偏紧通道；过半（≥50%）是宽通道指纹之一 | L1.5 紧/宽通道判定 |
| **重叠度** | 信号 K 与前根的重叠比例：重叠大 = 无净进展、控制权未易手，信号成色打折（与位置锚点的「叠加越多越好」正相反） | 形态关；先验表末行 |
| **EMA 读数** | 价格与 EMA 的相对位置、回调是否触 EMA、第一次收在 EMA 异侧 | M2B/M2S 的识别条件（触 EMA + 信号 K 大半截在正确一侧） |
| **趋势年龄** | 自趋势启动的 K 数与腿数：20+ 根 / 三腿以上 / 出现高潮 → 「老」 | 分支 D 的开启条件；高潮后冻结规则 |
| **MM 量法**（z 八锚点） | 实体/影线 AB=CD、被突破的前波段高低点、单腿回调的波段高低点、连续大 K 实体、spike & channel 投影——**单腿只与它回吐的那条腿比高**。多段尖峰（v2.3 补）：每段尖峰各自投影；旧投影在「目标被触及」或「反向腿收破该尖峰起点」时失效；多个有效投影并存时，目标与要塞一律取近的那个 | 各分支的目标行；分支 E 的下车位；汇合要塞的锚点计数 |
| **缺口分类** | 定义、状态机与入账门槛见下方专节《缺口 · 定义与入账规则》（定义稿 v0.1）。分类沿用突破 / 测量 / 衰竭；留开 = 后方城池未破，被回补的先后顺序即账本的出入记录 | L0 记账；目标审计 |

**嵌套读法（v2.2，用户点名）**：逐根读图时，每根 K 读两遍——
① 它是大结构里的一员（站在哪条腿、哪个位置）；
② 它是它内部那段小趋势的**结案报告**：收盘位置与上下影，就是小趋势最后的胜负。
由此三条执行口径：
- **计数只许在本级别内做**：回调腿内部的小趋势有它自己的腿和 H/L，但不许借它的摆动点来给本级别凑腿、凑 H2（与「不借小级别摆动点」同一条纪律的两面）。
- **回调的双重身份**：本级别的一段顺势回调，在小级别是一个完整趋势——它可以走完自己的两腿、也可以在里面完成自己的小型 MTR；「回调变反转」从来不是突然的，是小趋势先在里面翻了盘。M2 失败转化为 MTR 第一波，就是这个机制。
- **大 K 的读法**：振幅异常大的信号 K，先按「一段小趋势」读它的结局（收在顶端 = 小趋势强势收官；长影线 = 内部已打完一轮攻防），再回本级别定性——这是审计层「大信号等待」的原理：等下一根小信号，就是等小趋势打出一个可读的第二次尝试。

## 缺口 · 定义与入账规则（定义稿 v0.2，2026-10-30 用户拍板定版）

> 出处：z说交易画法（讲解视频 BV13neh6fE6g 拆解）+ 线索C《缺口篇 上》（BV1AW4R68EJh，其缺口体系自述学自 z）+ Brooks 原册 Video 11，三源一致。
> 本节取代此前一切旧口径：相邻 K 跳空、三根不重叠带（Micro Gap）、BO PB 双线带（v0.1 稿）全部废止。**缺口记单线。**

**定义（线索C 口径）**：缺口 = 有人被套、没出来的地方。一条缺口 = 一条锚线，被破之后价格一直没碰回来，锚线那侧的人就一直套着。

**两种锚（都收）**：
- **波段高低点**：相对高低点在**收盘折线**上认（折线拐弯的地方），锚价取拐点那根 K 的影线极值。价格破掉它 = 缺口开账。
- **强突破的起点 K 线**：大突破出发的那根 K（用户 2026-10-30 拍板收此锚）。在起点进场的逆势方几乎瞬间被套；起点线取起点 K 背向突破方向的极值（下破取其高点、上破取其低点——价格回到那里，起点里的人才全数解套）。
- **起点的第二重身份——趋势延续裁决线**（用户 2026-10-30 补）：起点是一条腿的出生线，回调深度以「起点 → 本腿极值」为全程量：**回吐过半（≥50%）= 这条腿算弱**（与底层「回调深度比 ≥50% = 宽通道指纹」同读数）；收盘破掉起点 = 这条腿的趋势失效（与 L1.5「回调变质：真失效 = 收盘破突破起点」同线）。所以起点线既是缺口锚、也是地图上必画的结构线：守住它趋势在，丢了它腿就死了。

**不记回踩极值线**（用户 2026-10-30 拍板）：v0.1 稿的第二条线与「回踩裁决成立与否」一并取消。缺口生死只看锚线本身：**破了就开账，碰回就解套销账，没碰到就是没解套**（差 0.07 也算没补）。原「成立 / 未成」之争随之消解——如示范图 219.05：不过是一条活了 3 根就被解套的缺口。04:19 的「回踩极值 = 被套据点」读法随线一并作废，不再引用。

**每条缺口记五项**：锚价与来源（波段点 / 起点 K）/ 套住谁 / 破于第几根 / 套深（开账后最大不利距离）/ 套时（已套根数）；状态只有两个：**敞开**、**已解套**（注第几根碰回）。反攻逼近锚线却没碰到 = 一次回补未遂，计数入账；两次未遂 + 反向跟进 = 救援方力竭（原「二次回补缺口失败」在本口径下的表述，与失败的突破、二次入场同源）。

**入账门槛（现阶段范围）**：缺口在 K 线之间到处都有（Brooks：每根趋势 K 都是一次突破尝试，most gaps have no predictive value）；**现阶段主账只收突破点落在据点、要塞上沿或下沿的波段点缺口，以及发生在沿口突破处的起点 K**。其余微型缺口不入主账，只汇总成趋势强度证据（瀑布中连续留开的微缺口串 = 趋势极强，读的是串、不是单条）。机械后果：facts 通道只盯地图线——收盘破沿 → 开账、逐根更新套深/套时/未遂计数、碰回 → 销账。

**读法（线索C 用法层，与 L0/L1 互证）**：套深 × 套时 × 是否给解套机会 = 趋势强度计（永不放人 = 最强趋势；走一步放一步 = 弱趋势/宽通道）；**谁也套不住谁 = 震荡区间**（最快判法）；缺口可作止盈位（顺势方赴约解救己方被套者，救完目的即终）。

## L0 · 记账（z 体系，永远先走）

```
查缺口账本：缺口在哪 / 哪一类 / 敞开还是已补 / 套住谁 / 双方解套位在哪
if 逆势方目标未审计完 → 不许顺势动手，先替对手推完剧本
if 单一缺口 + 单一位置 + 无到达行为 → 直接 else：不做（高胜率公式三件缺一不可）
```

## L1 · 语境路由（outer if）

```
if 上升趋势（HH+HL 结构完整，always in long）      → 分支 A
else if 下降趋势（LH+LL 结构完整，always in short） → 分支 B（A 的镜像）
else if 区间（两边止损都能赚钱、边缘清晰）          → 分支 C
else if 趋势已老（20+ 根 / 高潮 / 三推 / 楔形）      → 分支 D（反转，只观察不抢跑）
else → 空仓。看不懂就是最外层的 else，永远合法。
```

## L1.5 · 概率先验层（Brooks 经验，路由之后、点名之前）

> setup 回答「这是什么招」，概率层回答「在当前这种状态里，哪边赢面大、哪招升权、哪招关掉」。
> 先验只做三件事：**给分支升权/降权/关闭、改目标预期、改触发耐心**——不改仓位（期望归 RR 管，胜率归先验管，两条线不混）。
> 带确切数字的先验均有出处（手册/原册）；其余按「倾向」表述，不编百分比。
> 概率词标尺（v3.1，原册 V36）：Brooks 说 "probably" 即 ≥60%——本谱写「大概率」
> 一律按此刻度。v3.1 的数字先验已于 2026-10-29 对 54 册原册全文逐条核对，
> 出处以 Video 号标注；原册查无数字的（H2 胜率、缺口留开率）只许定性表述。

| 市场状态 | Brooks 经验先验 | 对分支的修正 |
|---|---|---|
| **紧通道**（回调浅、少重叠、斜率陡） | 趋势延续概率高；逆势尝试几乎必败；回调不会深 | 顺势分支全开且可提前（H1 可用）；分支 D 直接关闭；回踩目标不许等深——等深 = 没单 |
| **宽通道**（回调深、双边都能赚钱、斜率缓） | 本质是**斜着的区间**：涨多了会被卖、跌深了会被买；突破多失败或走不远；最终大概率演成横盘区间 | 按「半个区间」处理：分支 A 只留回踩类（A1/A2，且只在通道下半部）；A4 突破确认**降权**——破通道线先按假突破防；目标改看通道对侧线，不用趋势 MM 外推；分支 C 的边缘思维部分接管 |

**宽通道专项（用户 2026-10-29 点名）**：宽通道是本层最常用的修正——图看着是趋势、骨子是区间。判定：回调深度常达前腿 50%+、反向 K 频繁、双边止损都能赚到钱。命中后默认动作：① 顺势只打回踩、不打突破；② 目标 = 通道对侧，不外推；③ 通道线被破先按假突破处理（收回 + 回踩失败才改判）；④ 耐心等价格到通道的另一半再审 setup——在通道中部动手，两边都不靠。

**折扣兑现总则（v2.9 补，源自第十四至十七局四连亏 −460.65 的共性审查）**：
四连亏的死因各不相同，但病根是同一个：**折扣只记不收**——先验表里写了折价，
审计里也念了折价，最后入场条件却一分没紧。本总则把每种激活的折扣兑换成
硬性的关口调整，背景关审计必须逐条写明「本局激活的折扣 → 兑换成的收紧」，
只写「已考虑」不算过关：
- **抛物线高潮后的首次恢复**（样本：第十局 −117.18、第十五局 −114.35）：
  A1/A2 的第一笔恢复单，须满足其一才武装——修正自身打出更高低点结构
  （EMA 区双底/二次信号），或净 RR ≥ 2.5。单信号恢复关闭。
- **踩踏继承的翻转区**（样本：第十六局 −117.84）：翻转区全程收盘穿越 ≥3 次的，
  A5/B5 只许强信号 + 第二根确认；第一根小拒绝永不武装。
- **衰减边缘**（样本：第十二局 −144.36、第十七局 −122.71）：同一边缘被测 ≥4 次后，
  边缘入场须第二根收盘确认（失败须收出对方那根的振幅之外，见形态关棒内规则），
  且净 RR 门槛升至 2.0。
说明：三条兑换的共同祖宗都是谱里已有的原理（第二次尝试、库存消耗、高潮折价），
v2.9 只是把它们从评论变成收费站。代价自知：会滤掉个别后来走对的单（如第十五局
第 49 根 A5 被 RR 毙后价格穿过目标）——那是保费，不是误杀。

## 附 · 训练器执行附则（环境事实，不是树逻辑，v2.3）
