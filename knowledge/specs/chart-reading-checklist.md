# 眼睛检查清单 v0.1（图读判断的强制自问，从阿布原图盲考错处提炼）

定位（分工定版 2026-10-30）：识别以图读为准；本清单是图读时的核对表，
不是数据特征。考场 = 阿布原图盲考（brooks-image-exam），错处更新本清单。

## 读图顺序（不许跳步）

1. **先给单标签日型**：趋势日 / 区间日 / 通道日，三选一先落判，
   然后再补分段描述（盲考教训：爱用「两段式」绕开单标签，10-23 因此丢半分）。
2. **每个极端点必须点名**：全天高/低点、开盘极值、尾盘极值，逐个在
   {高潮 / 陷阱 / 双顶底 / 楔形 / MM 兑现 / 普通摆动} 里选一个，不许只报价位。
   （盲考教训：头肩底读成双底、MM 头肩兑现只读成「磁铁」——位置对、名错。）
3. **有高潮必查 MM**：出现买/卖高潮时，量出它的测量目标并核对是否兑现、
   兑现后是否回吐（10-28 尾盘高潮目标 7818 兑现即回落，是当天的收官逻辑）。
4. **复合形态扫描**：杯柄、头肩、旗形、三角逐个过一遍再说没有
   （盲考教训：10-21 杯柄结构读对但未点名）。
5. **Always In 分段标注**：每次翻转给时间和触发 K，不用全天一句话概括
   （盲考教训：10-22 午间反弹被读成转多，阿布口径是空头旗、AI 未翻）。
6. **收盘单独读**：最后 30 分钟是趋势收、高潮回吐、还是区间内中性收，
   单列一段（八日盲考此项全对，列为保持项）。

## 数字附件的用法（配合 core 分工）

- 价位以图读为准到 ±2 点；进入计划的价位必须换数字附件的精确值。
- 缺口账本只认附件（差 0.07 不算解套是眼睛的分辨率之外）。
