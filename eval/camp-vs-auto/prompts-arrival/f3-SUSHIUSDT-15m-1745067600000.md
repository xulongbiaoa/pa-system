# 常驻核心 core.md（每次判断必带；上限 2000 字）

版本：随仓库 VERSION。细则查卡片与附册，本文件冲突时以本文件为准。

## 交易者等式

期望 = P × 回报 − (1−P) × 风险 − 费用。胜率锚在五成上下是常态，利润来自 R 的不对称：先保 R 的形状（止损在结构外、目标按序列取），P 只求不虚报，禁止一切偷胜率的姿势（抢跑、缩止损、目标改近、摸顶抄底）。

设计目标盈亏比 **2:1**（赢 2R 亏 1R，毛口径；扣费后净 RR ≈ 1.95，用户 2026-10-30 定）。红线 1 的 1.5 是**地板不是目标**：1.5–2.0 之间的单子合法但不是想要的，画目标时应按 2:1 取，取不到 2:1 要说明是被哪条结构挡住（最近的要塞/目标位），不许默默改近目标凑合格。

## 读图顺序（不许换序）

1. 记账：缺口账本——敞开缺口在哪、套住谁、套深套时、双方解套位。
2. 定性：市场三目的（突破套人 / 赴目标位 / 解套打平）+ 趋势 MM 第 0 查（未达 / 已达）。
3. 画目标：双方目标位全画（MM 锚点、单腿口径）；顺势动作前先审计逆势方目标走完没。
4. 找触发：只在预画的决胜点（要塞级支撑/阻力）上、只用核心三族 setup 扣扳机。
5. Brooks 结构、形态、术语作第二层校验；单个形状不构成入场理由。

## 五条红线（裁决层代码强制，本文件只声明）

1. 净 RR < 1.5 否决（费用按净口径：入市价 0.05% / 限价 0.02% / 出场 0.05%）。计价基点（2026-10-31 裁定，按 Brooks v30：等式锚在自己的入场价）：市价计划按决策收盘与计划入场价取保守者；**限价计划按事前写明的限价入场价计**，未成交风险由未成交留档单独记账，不许事后挑价。
2. 止损放结构外加缓冲，不压整数位与摆动极值；持仓中禁止缩止损、禁止改近目标。
3. 单笔风险 1%；名义按现金倒算封顶。
4. 入场截止（2026-10-30 修订，范围定版）：只约束 trainer 局内——局内窗口末尾前 10 根不开新仓（150 根窗口即 Bar 140），目的 = 保证已开仓单在局内仍有足够前向 K 线可评估，而不是限制在窗口末尾做决定。标注／试点不受此限：决策点即「当下」，决策点收盘价即合法入场时点；决策点之后 300 根为该单生命周期，只用于判胜负，不参与决策。配套三条：① 触发 K 必须已收盘且不晚于决策点，不得用决策点之后的数据补触发；② 入场价只能是决策点收盘价，或决策点当时写明的限价（成交与否按后续 K 线判），不得事后挑更好的历史价；③ 止损与目标在决策点写定，生命周期内不得改（缩止损、改近目标仍按红线处理）。
5. 前提破（收盘越过前提线）即市价出场，不等止损。

## 生命周期与评分口径（2026-10-30 定版）

生命周期 300 根：走完既未触止损也未触目标的，按第 300 根收盘价平仓计入 PnL（时间止损；回放层现行实现与此一致），**不得标记「无结局」剔除**——剔除磨完的单子会系统性高估胜率（生存偏差，2026-10-30 用户定）。到期单以 exit_reason=window_end 单独标记，既不剔除、也看得出占比。生命周期按根数计、跨周期不可比（300 根在 15m 是 3 天、在 1d 是 300 天）：每段元数据必记周期，评分必须按周期分档汇报，跨周期汇总须注明污染风险。自然时间口径（固定 7 天）未定版：评估时可双算对照（回放层 bars_for_days），两种口径结论不一致时以分档结论为准，不许只报好看的那个。

限价口径（2026-10-30 定）：① 成交从严——价格必须**穿越**限价才算成交（买单低点 < 限价、卖单高点 > 限价），仅触及不算；② 未成交单必须留档单独统计，不许丢弃（未成交率是样本选择偏差的度量：差一点没回来的可能是最好的单，砸穿才成交的往往是最差的）；③ 生命周期锚在决策点，成交晚不顺延窗口。

## 假设格式

主假设 + 备选 + 接管条件（什么事实出现就易主）。**不用数字权重**（假精确，用户 2026-10-30 裁定）。易主是带触发事实的事件，留痕。

## 输出

判断层只输出 schema 规定的 JSON：语境定性、命中的 setup 与成色（合格 / 不合格两档）、计划五格，或不做的原因（枚举）。**识别与执法分工（2026-10-30 晚定版）：语境、形态与 setup 认定以图读为准**（阿布原图盲考：纯看图日型 3.5/4、价位误差 1–2 点；数据特征同题语境 0–1/2）；特征包降为**数字附件**——计划价位、账本与 RR 必须引用其中的精确数字，特征置信为「未定」的不得作放行依据；附件的 trend 机器标签与图读冲突时以图为准，不许单独支撑语境结论。

## 空仓合法

空仓是合法且常见的输出。不清楚不做：成色含糊的位置、信号、背景一律不做，不打折放行。判单只看逻辑链与纪律：逻辑完整、四关诚实通过的单子亏了也是好单；跳关、事后补逻辑的单子赢了也是坏单。


# 路由卡 router.md（每次判断必带；上限 800 字）

按特征包字段判语境，命中后只加载对应 setup 卡片（至多 3 张）。

## 趋势（上升 / 下降）

特征：趋势状态分数同向（HH+HL 或 LH+LL 序列成立）、缺口账本有同向敞开缺口（套住逆势方）、趋势 MM 状态 = 未达。
加载：M2B / M2S（顺势唯一入场）；突破事件卡（只定方向与锚，不直接入场）。
MM 已达 → 趋势标「成熟」：顺势菜单关闭，转高位/低位震荡审，翻面与 MTR 卡升权。

## 交易区间

特征：谁也套不住谁（账本无持续敞开缺口）、摆动序列无方向、价格在要塞带之间往返。
加载：突破失败翻面卡（区间突破默认假，先审失败面）；区间边缘观察项不执行（复牌条件：核心三族满 20 笔计分样本）。

## 反转候选

特征：老趋势（年龄/腿数足）+ 两腿衰竭尝试 + 趋势线突破（TBTL）。
加载：MTR 卡（门最严，三件套缺一即关）。

## 空仓

特征任一：语境判不出、关键特征置信 = 未定、决胜点不在测试区、无卡片命中。
输出 no_trade_reason，不许硬凑候选。

## 证据组合（研究级，不占菜单名额）

特征：账本有敞开缺口。附加 G1 汇合要塞卡：条件矩阵 R1–R3 必需、
V1–V3 否决，证据按同源组去重；不齐只挂起，不降格凑单。

## 入场方式分工（2026-10-31 审计定版）

- 顺势延续（A1/A2/B2）：stop 触发，入场价 = 信号 K 极值外侧。依据：
  阿布默认 stop 单（v32 s3/s38）+ 核心原则第 12 条（往上挂单优于往下
  接单）。判读层此前默认限价化属未裁定的漂移（五轮候选几乎全限价）。
- 翻面（B3/G1）与区间边缘：限价合法——限价位即决胜点本身，阿布在紧
  区间亦只用限价（v18 s108）。H1 对限价计划按限价入场价计价（已定版）。
- 顺势计划若写限价，须在 strongest_countercase 说明不用 stop 的理由。

## 出场口径（2026-10-31 开启分批出场）

- exit_mode=scale（targets≥2 时默认）：首目标出 1/2、次目标出 1/4、
  余 1/4 跟末目标；各档共用止损与 void、不移保本（简化口径）。
  依据：Brooks 第一目标至少出一半（v21 s92）、2x/3x 分批配比（v36 s21）。
- exit_mode=full：全仓首目标结算（H1 计价口径不变，仍按首目标）。
- H1 的 RR 执法与结算分工：计价看首目标（方程成不成立），出场按
  exit_mode（钱怎么拿回来）——两者不再是同一件事。


# B3 突破失败翻面

出处：骨架 v1 突破事件族（原 A5 反手面）；本地两笔大胜单出自此面（+452.85 / +155.73，样本不足，只作倾向）。

适用语境：突破已发生（含区间突破、决胜点突破）；回收窗口 1–3 根内裁定失败。

位置要求：入场位 = 翻面位（被破沿口线）；翻面位第一次回踩优先审。

触发条件：窗口内收盘收回位内 + 反向跟进。窗口第一根回调属于突破方，不算失败；窗口走满未收回 → 失败不成立。触发 K 须有方向实体（实体占比与 CLV 由特征包给出），盘中创反向新极值者降格审。

止损规则：突破腿极值外侧 + 缓冲。

目标序列：原区间/原结构对侧边缘 → 更深 MM；按序列逐级算净 RR。

失效与降级：入场后价格再收回突破方向位外 → 前提破，市价出。

常见误判：① 窗口没走满就抢翻面；② 目标只取翻面位近目标、丢掉序列（RR 关会否决，属计划问题不是形态问题）。


# C1 MTR 主要趋势反转

出处：Brooks 十大第 1 位；V22/V11/V21（自标波段胜率约 40%，靠 RR 不靠胜率；先验未验证）。

适用语境：三件套缺一不开审——① 老趋势（趋势年龄与腿数足、远离 EMA 倍数大）；② 两腿衰竭尝试（逆势方两次尝试走远均失败）；③ TBTL：趋势线被破且回测失败。

位置要求：入场落在原趋势极值区 / 要塞沿口，即决胜点本身；中部不审。

触发条件：三件套齐 + 反转方向信号 K 合格级以上；全新全审，不许沿用旧审计。

止损规则：原趋势极值外侧 + 缓冲（通常较宽，名义按风险倒算，装不下就不做）。

目标序列：最小目标（原趋势回调极值）→ 反向 MM → 对侧要塞。

失效与降级：价格收回原趋势方向并创新极值 → 前提破出场；三件套任一被后续 K 否掉，未入场候选直接作废不挂起。

常见误判：① 只有趋势线破就当反转（破线只是刹车信号，不是掉头信号）；② 第一次衰竭尝试就抢（要两腿）；③ 用 MTR 的名义做区间中部逆势单。


# G1 汇合要塞：回补缺口 × 落点叠加 × 到达行为（研究卡，未定版）

出处：用户高胜率公式（2026-10-26 提炼）——预判回补某缺口 + 落点与
MM 等多锚叠加 + 到达时出现明显行为，三者齐备才做。本卡是该公式的
条件矩阵定版：**研究级，不在生产菜单**，不占用核心三族名额，不改
core 红线。晋升条件：dev/val 消融对照（逐层去证据层比胜率/期望/
样本量/入场延迟）样本外支持后，另行定版。

适用语境：不限趋势/区间；前提是账本里有敞开缺口（pack.gaps.open
非空）且方向有账——被套一方必须回成本区打平，回补方向即候选方向。

## 条件矩阵（判断层逐项申报，裁决层 H7 执法）

**维度原则（本卡的计数单位）**：多证据是为入场质量服务的，计数
按**维度**不按条数——同一维度的证据堆再多也只算一票。必需三项
各占一个维度：R1 账本（谁欠谁、方向有账）、R2 位置（落点在哪、
多锚叠加只升本维度的等级，不新开维度）、R3 触发（到达时行为）。
R2 内部锚再多也只是「位置」一维；真正的质量增量来自维度之间
互证。增强项 E1–E4 各自标明维度，与必需同维度的只加成色、
不算新维度；E3 过程、E4 背景是必需三维之外的新维度。

必需（缺一即不合格；状态只许 met 才放行）：
- R1 账本方向〔维度：账本〕：目标缺口在决策时仍敞开（gaps.open 有条目，锚线价位
  明确）， trapped 一方与候选方向构成回补关系（做多 = 向上回补
  套住空头的缺口；做空镜像）。证据 ref 指向该缺口条目。
- R2 落点叠加〔维度：位置〕：计划落点（入场/触发位）落在缺口锚线 ±0.25×段均幅
  内，且同址有至少一组**独立同源组**的锚：MM 投影目标
  （pack.mm.candidates）、要塞带（pack.fortress.bands）、波段高低
  点（pack.swings）。同源不算第二锚：缺口锚若源自某摆动高低点，
  该摆动点与缺口同组（groups 须如实申报，R2 至少 2 组）。
- R3 到达行为〔维度：触发〕：价格已到达落点且出现下列之一——① 账本回补未遂
  （attempts ≥ 1）后反向跟进；② 到达后 1–3 根内顺势强信号 K
  （强 K 口径见 config：振幅 ≥1.3×剪均幅且实体 ≥60%）收在落点
  顺势侧；③ 第二次回补未遂（二次回补失败）。只有位置没有到达
  行为 = 挂起（pending_conditions 写明等什么），不许抢跑。

增强（只加成色，不抵必需缺失、不抵否决）：
- E1 二次性〔维度：触发〕：到达行为属第二次尝试（回补未遂第二次
  / H2·L2 同源）。
- E2 要塞级〔维度：位置〕：落点同址独立锚 ≥ 3 组。
- E3 过程衰竭〔维度：过程〕：接近落点的过程显示逆势方衰竭——
  推进幅度递减、三推、回补未遂深度逐次变浅（账本 depth/attempts）。
- E4 背景同向〔维度：背景〕：大级别语境与账本回补方向同向
  （图读认定，非附件 trend 标签单独支撑）。

否决（任一 met 即拒；任一 unknown 同样拒——关键否决不许未定）：
- V1 逆势方目标未审计：顺势候选未先审计逆势方最近目标（MM/要塞）
  是否走完，或审计结论是「未走完」却仍顺势。
- V2 账本已销账：目标缺口已被回补关闭（立论消失）。
- V3 不在预画决胜点：落点不是预画的据点/要塞边缘（图读认定），
  属图上没标过的位置——默认小据点，不做。

## 申报格式

candidates 里 setup="G1" 的候选必须带 conditions 数组（rule_id /
role / status / dimension / evidence_refs / groups / note）与
strongest_countercase（最强反证一句话：什么事实最可能让这单错）。
维度由 rule_id 固定映射（R1 账本 / R2 位置 / R3 触发 / E1 触发 /
E2 位置 / E3 过程 / E4 背景 / V1 反证 / V2 账本 / V3 位置），
申报维度与映射不符即错位，validate 与 H7 都拒。证据计数先按
groups 去重（同源一票），再按 dimension 数维度（同维一票）。

## 止损、目标与失效

止损：落点结构外 + 缓冲（沿用 H2 口径，不压整数位与摆动极值）。
目标序列：缺口对侧边缘 → 下一完好要塞/MM，逐级按现价口径算净
RR（H1 首目标 ≥1.5 不变）。失效：收盘越过落点对侧（plan.void）
或目标缺口被反向回补关闭 → 前提破，市价出。

## 常见误判

① 把同源锚数成多证据（前高 = 区间上沿 = 阻力，其实一个高点）；
② 只有 R1+R2 就抢跑，缺 R3 到达行为——公式里行为是扳机不是点缀；
③ 用增强项抵必需缺失；④ 缺口已销账还按原立论做（V2）。
