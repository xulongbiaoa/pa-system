# W08 对齐评估规格 v1（2026-10-31 运行前冻结）

## 目的

按方案 §15 第三套：固定模型、数据截止与历史状态，对比「直接读原始数据」与「读战场查询包」两种输入下 AI 判读的质量与成本。质量与成本**分别报告**，不合成总分。

## 语料（截止与历史状态固定）

- 标的：BTCUSDT 15m、ETHUSDT 15m，各 1000 根已收盘 K 线，运行前新鲜抓取并冻结在 `eval/w08/data/`（判读员只读任务书指定的那一份臂材料文件；该目录其余文件禁读）。
- 历史状态：新鲜构建、无既有大脑假设与观察计划（两臂同为零起点），J1/J2 从零提出。
- 考试卫生：真值由脚本抽取后密封于 `ground_truth.json`，数值不进入任何判读通道；判读员不得读取 `eval/w08/` 下除任务书指定材料外的任何文件，不得读对方臂材料。

## 双臂输入

- **战场组**：只读 `eval/w08/data/pkg_<SYM>.json`（scene + changes + 双角色活动线），可用 python 消化。禁止读 bars 文件。
- **直接组**：只读 `eval/w08/data/bars_<SYM>.jsonl`（原始 OHLC），可用 python 自行计算。缺口定义按 v0.2 口径随任务给出（锚线、major (5,5) 摆动才立账、整根分离立账、触锚关账、完整往返计一次测试）。

## 固定题目（两臂同卷）

事实题（每题子项独立计错）：
- F1 最新收盘价；最后一根的开盘时间（ms）。
- F2 当前开放缺口总数。
- F3 现价上方最近的开放缺口：锚价、方向、与现价距离。
- F4 现价下方最近的开放缺口：同上（不存在则答 null）。
- F5 被测试次数最多的开放缺口：锚价、测试次数、最近一次测试的开始/结束根开盘时间。
- F6 全场序号最大的已结束推进段：方向、净推进、回吐比（直接组以自算的最近一段完整推进作答，口径差异单独标注）。
- F7 多方与空方各自最近一段行动：关联位置（摆动点标识或价位）、是否已结束、净推进（直接组以自算最近一段方向推进作答）。

判断题：
- J1 主假设一段话：哪方在守/攻什么位置，引用证据（战场组引用对象/事件 ID；直接组引用根时间/价位）。
- J2 观察计划：观察位置、等待行为、取消条件（四段链取三段，触发可并入行为）。
- J3 动作裁定：WAIT 或 CANDIDATE，二选一并给理由。

答不出必须答 unknown 并把题号列入 unknowns，不许猜。

## 评分口径（评分时冻结于此）

- **事实错误**：子项与真值不符计数。价位类容差：锚价/收盘须精确到 0.5 以内（ETH 0.05）；计数须精确；距离容差 1%（ETH 0.3%）；回吐比容差 0.05。
- **序列错误**：事件/段的先后次序答反，单独计。
- **候选召回**：J2 观察位置命中真值关键位（F5 最多测试缺口，或 F3/F4 最近缺口，三者之一）记命中。
- **错误放行**：J3=CANDIDATE 但其引用证据存在事实错误、或观察位置不在真值关键位，记 1 次。
- **unknown 率**：unknown 子项 / 全部事实子项。
- 真值 = `ground_truth.py` 从战场确定性状态抽取（评分人持有，判读员禁读）。注意：真值源于系统自身状态，本考试测的是**输入表征对齐**（直接组能否复现同一事实集），不是对外部专家 Gold 的成绩——报告必须带此口径自警。

## 成本口径（与质量分开）

- 输入规模：臂材料字节数。
- 判读耗时：子代理墙钟（近似，含其计算时间）。
- 不采集 token（子代理通道无可靠计数），报告中明示缺失。

## 运行规则

- 每臂每标的运行 1 次；重复运行不算独立样本（§15）。
- 判读输出写 JSON 到指定路径，字段按任务书 schema。
