# 第三臂预注册：AUTO + 冻结地图附件（hybrid）

- 日期：2026-10-31（用户当日指令「跑第三臂：同 20 事件测 AUTO+地图附件」）
- 母实验：`camp-vs-auto-eventpaired-prereg-2026-10-31.md`；裁决：`camp-vs-auto-eventpaired-verdict-2026-10-31.md`（含 ev01/ev07 复核附记）

## 动机（来自已裁决数据的结构事实）

- AUTO 两笔亏损各缺一条战役信息：ev01 缺「本腿 MM 已达、趋势成熟」（地图里预写了成熟条款，CAMP 因此作废避开 −1.049R）；ev07 缺「价格已离开决胜点」（CAMP 认出同一翻面机会但离点不追，避开 −0.435R）。
- CAMP 的病在管道：产量 0、地图提前 90 根的保鲜期、到达遍格式不合格 6/20。AUTO 的管道恰好相反：单遍、格式 0 错、候选率 15%。
- 假设：把冻结地图降为 AUTO 单遍判读的**附件**（只供位置与战役状态），识别与产出仍归 AUTO 单遍，有机会同时拿到两边的好处。本臂测这个假设，不测新的交易规则。

## 第三臂定义（唯一变量 = 地图附件 + 点名纪律）

- 语料、事件点、图（B 图）、知识层、gate、300 根回放、计分口径与前两臂完全相同（同 `eval/event-ab/` 语料）。
- 提示 = AUTO 臂原提示（`prompts-auto/`）全文 + 文末追加「战役备忘」一节：本事件冻结地图 JSON 原文（与 CAMP 臂同一批地图，事件前 90 根画定）+ 三条使用规则：
  1. 候选必须写 `point_id` 点名地图中的一个决胜点；决策根收盘不在该点 [lo, hi] ±0.25×段均幅内，该机会只许记 pending，不许 qualified；
  2. 地图假设的 void_if / 作废条件已发生时（如价格已越过地图标注的 MM 投影且该假设顺势分支按图关闭），对应方向候选不许 qualified；
  3. 地图只供位置与战役状态；形态、触发、成色仍以图读为准；位置冲突时以地图为准。
- 违规机械检查与 CAMP 臂同口径：qualified 候选的 point_id 不存在、或决策收盘不在所点名点带宽内，计 violations。

## 裁决判据（预先声明，先结构后绩效）

- **A 拦截**：ev01 与 ev07 两事件 hybrid 均无成交（路径不限：未写候选 / 未 qualified / gate 拒 / 未成交均算拦住，但报告须写明各自路径）。
- **B 纪律**：violations = 0 且 format_errors ≤ 1。
- **C 产出**：qualified 候选 ≥ 2（AUTO 为 3；少于 2 视为产量塌方，结合只剩 CAMP 的弃权）。
- 三项全过 → 结合在结构意义上成立，进前向影子 v2 的设计议程（不自动上线）；任一不过 → 按不过项定位失败原因（附件没被用 / 纪律没执行 / 产量塌），不改判据重测。
- 绩效只作参考：hybrid 每机会 R、配对差 hybrid − AUTO 的 bootstrap 95% CI（种子 20261031，同母实验）。样本内 resolved 预期个位数，CI 含 0 不作任何臂间胜负宣判。
