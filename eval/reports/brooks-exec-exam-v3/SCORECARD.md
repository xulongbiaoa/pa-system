## 裁决

1. **眼主导对「准入层」有效**：两个数据侧否决点（感知门、G1 几何
   到达）在判读层都已消失，候选从 0 → 3 且方向 3/3 对齐。架构变更
   的目标达到了。
2. **绑约束下移一层：计划定价**。3 个候选全死在 H1——首目标都只取
   到最近结构（区间上沿、近端摆动），净 RR 0.18–1.41。判读员会认
   形、会点名结构（三个 stop_basis 都真实存在且止损越界正确），但
   不按目标序列算账：要么把目标放远到序列下一站，要么用 cap_reason
   说明封顶，要么不写候选。现在三样都没做。
3. **格式回退**：8/8 → 6/8。新提示把 void 的结构化要求埋在长句里，
   两个判读员各漏一半（一个缺文本 void_if、一个缺结构化 void）。
4. **犹豫的新形态**：dp7 把可执行候选降格为接管假设、dp5 以前提
   从严空仓——「多等一根」从触发层退到假设层/前提层，未根除。
