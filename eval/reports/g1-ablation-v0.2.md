# G1 维度消融报告 v0.2（事件采样 + 双通道 + 职责归位）

- 日期：2026-10-30 晚。底料：`eval/datasets/fresh/` 30 段（同 v0.1）。
- 与 v0.1 的三处修正（用户拍板「三件一起改」）：A 决策点改机械到点事件；B 判断附截断图（图读优先、数字附件定价）；C 提示职责归位（过卡即写候选，数字执法归 gate）+ `pending_conditions` 结构化对象化。
- 污染声明沿用 v0.1（判断子代理继承主对话上下文；独立 API 通道未建成）。

## 事件采样框（v0.2 的方法核心）

事件定义（`eval/build_events.py`，纯因果、只用位置维）：价格在赶路后首次触及一个**早已存在**的点位——敞开缺口锚或要塞带（锚 ≥3 组、带宽 ≤2× 段均幅）。四道防伪：① 点位须至少早 5 根存在（防带在脚下新生）；② 触及前 5 根内收盘须曾离点 ≥1× 段均幅且上一根收盘在带外（赶路才算到达）；③ 同一点位全段只记一次；④ 每段采样至多 2 个事件、间隔 ≥20 根（纯时序选取，与结果无关）。

结果：30 段选出 **60 个事件**（每段 2 个，位于第 60–151 根）。已知局限：要塞带覆盖面广，事件以要塞触及为主、缺口事件为少数；时序选取偏向每段较早的到达（首达偏差）。

## 结果

60 事件盲判（图 + 提示）：格式合规 60/60；结构化 pending 60/60 份（v0.1 为字符串）；在 **G1 被显式审议**的份数未单独计数（本轮判读普遍给出 G1 挂起理由，见各判断 pending）。

| 漏斗级 | n | 说明 |
|---|---|---|
| 事件 | 60 | |
| 合格候选 | **6（10%）** | v0.1 为 0/55——三项修正后触发率 0% → 10% |
| 过 gate | **0** | 6 单全部被 **H1（首目标净 RR<1.5）** 拒绝；其中 1 单另兼 H2 |
| 成交回放 | 0 | L0 空集，L1/L2/L3 仍无从比较 |

候选构成：B3 ×4（FET 15m、HBAR 15m、HBAR 4h、LDO 1d，均为下破失败翻面做多）、A1 ×2（ETC 1h、ONDO 1d）；**G1 候选 0 个**——各判断普遍将 G1 挂起，缺失集中在 R3 到达行为与具体落点到达，判断层对旗舰卡执行严格、没有凑数。

### RR 几何：本轮真正的约束点

6 个候选的首目标 RR 为 0.60–1.20，全部死于 H1 的**首目标口径**（gate 与回放同口径：只按 targets[0] 结算，代码注释在案）。但其目标序列的末目标 RR 有 4 单 ≥1.42。影子回放（不改裁决、仅诊断）两种结算口径的总账几乎相同：

| 事件 | setup | 首目标结算 | 末目标结算 |
|---|---|---|---|
| ETC 1h@b64 | A1 多 | target +0.496R | target +0.696R |
| FET 15m@b66 | B3 多 | stop −1.059R | stop −1.059R |
| HBAR 15m@b73 | B3 多 | target +0.878R | target +1.641R |
| HBAR 4h@b64 | B3 多 | target +1.178R | stop −1.016R |
| LDO 1d@b101 | B3 多 | target +0.870R | target +1.528R |
| ONDO 1d@b89 | A1 多 | target +0.859R | target +1.417R |
| **合计** | | **+3.222R（5 胜 1 负）** | **+3.208R（4 胜 2 负）** |

读法（三条，均为 n=6 的弱证据，只作方向参考）：① 管线已全线贯通且每级可审计，v0.1 的「零机会」系采样框+无图+职责内化三因，已证伪其一（三项修正后同底料产出候选）；② 约束点已下移至 RR 几何——到点事件处最近对向结构封顶首段回报，与用户既有「RR 被结构封顶」教训同构；③ 结算口径之争在本样本上不分胜负（两口径总账打平、分布不同：末目标口径赢在 HBAR 15m/LDO/ONDO 的续航，输在 HBAR 4h 的回吐），**没有证据支持为救这 6 单改结算语义**。

## 结论（不下结论，按既定纪律）

- 维度消融仍不可识别：G1 候选为 0、过 gate 成交为 0。G1 不晋升、不否决，维持研究级。
- 本轮净产出：① 事件采样框可用（定义与防伪四条已固化在 `build_events.py`）；② 双通道判断可稳定产出合格候选（10%）与全结构化 pending；③ 裁决层首次真实上班（6 次 H1 执法）。
- 若要专门测量 G1，下一步须把采样框改为**账本事件**（价格回补敞开缺口锚的到达，叠加点优先），而非泛要塞触及——这是新的采样设计，待用户拍板，不在本轮范围内。
