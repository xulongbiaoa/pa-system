# G1 维度消融 v0.1：随机决策点采样下不可识别（2026-10-30）

## 要测什么

G1（汇合要塞）的设计主张：多证据按**维度**计数——账本（R1）×
位置（R2）× 触发（R3）三维互证的入场，质量应高于维度更少的入场。
消融分层（同一批候选、逐层加维）：

- L0：全部过 gate 的合格候选
- L1：L0 中方向与敞开缺口回补方向一致者（账本维，机械近似）
- L2：L1 + 入场价落在缺口锚 ±0.25×段均幅且同址有独立锚（+位置维）
- L3：判断层申报的 G1 全矩阵候选（三维齐）

逐层比胜率 / 期望 R / 样本量；任一层 n<30 只报数不下结论。

|---|---|---|---|---|---|
| 旧 dev（管线批） | 25 | 25/25 | 0 | 0 | 0 |
| 全新段 | 30 | 30/30 | 0 | 0 | 0 |
| 合计 | 55 | 55/55 | **0** | 0 | 0 |

空仓原因分布（55 段）：**位置不对 30（55%）**、成色不合格 21
（38%）、无命中 4（7%）。

**L0 为空集，L1–L3 无从比较——维度消融在本采样设计下不可识别。**
这不是「维度无效」的证据：随机窗口的第 180 根，极少恰逢「价格
站在决胜点上 + 账本有账 + 到达行为已出现」。与既往三批同形：
外部复核 39/41 空仓、gold-run 28/30 空仓、阶段 5 试点 10/10 空仓。
触发率本身测出来了：**随机单决策点触发率 0/55**。

## 本轮真正测到的东西

- **G1 的判断层行为效应是真的**：55 份判断中 50 份显式审议了 G1；
  55/55 都写了 pending_conditions（挂起条件具体到价位、缺口锚与
  到达行为，如「等 0.3391–0.3512 汇合区到达行为」）。矩阵在判断层
  的实际作用 = 把「差哪一维」写成可核对的等待条件，而不是凑单
  工具——零硬凑、零维度错位、零格式造假。
- **主导拒绝因是位置**：过半决策点价格根本不在决胜点上。这与
  预演制的第一性自洽：决策只在点上发生，随机时点采样系统性地
  错过点。评测设计与执行 doctrine 打架，是本轮最实的发现。

## 修正提案（待用户裁定，未动工）

**位置条件采样**：切段时先机械初筛——只收决策根收盘落在「敞开
缺口锚或要塞带 ±0.25×段均幅」内的窗口（只用位置维筛采样框，
不看方向、不看到达行为、不偷看未来），再盲判。这样采样框与
实盘一致（只在点上评估入场），账本维与触发维仍是被测变量。
规模估算：需要约 60–100 个到点决策点，才可能攒出 20–30 个
候选供分层。在线等价物是阶段 7 前向影子（决胜点挂 pending、
触发即记录）。
