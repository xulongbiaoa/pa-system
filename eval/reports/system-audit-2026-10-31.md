# pa-system 结构审计（2026-10-31）

应用户问：结构这么多了，逐项认定——哪些做得好、哪些欠缺、
哪些是负优化；入场点与阿布是否对齐；结构之间有没有打架。
证据基：eval/reports/audit-evidence-ledger.md（22 项实证表 +
35 条 bug 清单，只汇编）与 audit-brooks-anchors.md（原册锚点，
全部带 video/slide 出处）。本报告只下认定，不改任何规则。

档位：A 有实证站得住 / B 设计合理未验 / C 结构性欠缺 /
D 负优化（有证据显示有害） / E 空转（存在但从未生效）。

## 总判断（先说最重要的一句）

**本系统目前没有任何一条交易规则拥有绩效证据。** 五轮消融
官方成交合计 2 单（均 void 出场小亏），trainer 新批 4 笔，
简单基线期望 ≈0（CI 含 0）。所以下面所有 A 档认定的都是
「防错 / 对齐 / 可执法」维度的好，不是「能赚钱」维度的好。

系统真正的产出在另一本账上：它是一台**防自欺机器**——
35 条接线/口径 bug 已修 28 条，其中包括自产自销的旧 gold、
H1 入场价博弈洞、判断层自我过滤（0/55）这类会让任何回测
系统自欺的经典死法。每一层都在拦，是交易样本这么少的
直接原因：**拦截系统的产出率天然低，测量系统又需要样本，
两者在结构上互相饿死**（见打架 #5）。这是当前全局的形状。

## 逐项认定

### 宪法层（core / 红线）
- **红线 4（决策点合法性、禁事后挑价）**：全系统被实证
最多的原则——H4 范围定版、限价口径、博弈洞修补都以它为根。
- **交易者等式（RR 先行、P 只求不虚报）**：gate 只执法了 RR 一半；P 在系统里没有任何
量化载体，全靠判读员定性（H7 是唯一把 P 结构化的尝试）。
阿布的等式是 P×R 两项，我们的执法只有 R 项——这是有意
的分工，但要记账：H1 地板本质是「用 RR 门槛代偿缺失的
P 估计」，不是阿布原法（见对齐表 #3）。
- **空仓合法 / 不清楚不做**：与骨架、预演制
一致；系统层面的代价见打架 #5。
- **纪律轴与盈亏轴分开记**：trainer 新批执行 4 局，
无对照实验。

### 识别层（感知 + 图读）
- **眼/数据分工**：全系统证据最硬的一条——纯看图日型
7.5/8、价位误差 ≤2 点 vs 数据包语境 0/2；A/B 语境轴 6/6。
- **摆动 trend 标签（作附件）**：段语境 26/30 为八个
变体中最优。**同一个标签作日型用**：无日型层，两日
全错。结构本身没错，错在用途越界——而它还在越界（打架 #8）。
- **缺口账本状态机**：五轮采样与全部 G1 审议都靠它
运转；小欠缺是 attempts 双定义（打架 #7）。
- **要塞带**：粒度不稳（25 点巨带 vs 7 条碎带），测次
随带宽漂移；v0.3 overlap 标记已证失效（50/51 恒真）。
它同时是 R2 判定、事件采样、flags 映射的上游——感知层
最弱的一块，欠缺会向下游传导。
- **regime/纹理原型**：金标准 11/30 不过线，
路线已废止。负优化已被处置，留作流程教训：先考场后转正
的顺序救了它。
- **trend_age.legs**：结构性恒为 1（dev 31/31），一个
恒定字段还在进提示，是纯噪声，无人修。

### 判断层
- **契约 + validate + 职责归位 C**：候选 0/55 → 6/60 →
各轮稳定产出；格式失败 v0.5 归零；pending 结构化使
「差哪一维」成为可核对的等待条件。
- **路由（机器标签选卡）**：菜单在判读开始前就被
数据标签定死，图读只能改定性、改不了菜单——与分工定版
正面相悖（打架 #1）；且历史上出过「永不带 C1/B2」的整族
盲区 bug。现行版有冲突升权兜底，但趋势干净时 B3/C1 仍
不在菜单内，而 B3 恰是五轮候选的主力 setup。
- **召回（样本 + 原册页）**：泄漏已修；收益从未单独测过。
- **G1 + H7 条件矩阵**：可成形、可执法已证（v0.5
H7 通过 2/2、零凑数零错位）；绩效不可识别（分层五轮皆空）；
成本真实——10 项申报的格式面，两轮里 9 个候选 3 个死于
格式，损耗专挑最稀有的产物。
- **假设主/备 + 接管条件**：格式稳定运行，无绩效证据。

### 裁决层（gate）
- **H1（首目标 + 双基点）**：博弈洞有逐档抬价实验
（RR 2.59→7.98、实现 R 反恶化）；限价基点有原册依据与
用户裁定。减分项：与 2:1 设计目标的锚定问题（打架 #3）。
- **H2 止损结构外**：两次误杀（整数位死代码、DOT
小级别摆动）都有案卷并已修，修后与外部复核计算一致。
- **H3 风险上限**：从未被真实样本压到过。
- **H4 截止**：范围定版后无争议。
- **H5 引用完整性**：只查 gaps/ema/trend 三个根；
fortress/mm/pullback 的置信字段不查——判读引用「边界」
置信的 MM 候选作放行依据时无人拦（v0.4 判读实况里出现过）。
- **H6 模式停牌**：至今从未生效（各轮台账恒空，
h6_active 恒 False）——但阈值「样本 ≥3 且 0 胜」统计上
站不住：真胜率 45% 的模式连输 3 把的概率约 17%，台账一旦
攒够样本，它会先以误杀的方式生效。与本系统「绩效结论
需 n≥30」的回放纪律自相矛盾（打架 #6）。
- **S1–S3 软降仓**：S1 的 parabolic 判据根本不存在
（PENDING 登记）；S2/S3 生产者已接线，但全部真实运行里
**零触发记录**。「降仓层」在账面上存在、在实证上是空的。
- **凯利 sizing**：提案未生效；文件自算现阶段正确仓位
为 0。结构在、数据无，维持提案态即可，但别把它算作已有能力。

### 回放 / 测量层
- **回放口径（300 根生命周期、时间止损计入、限价穿越成交、
未成交留档）**：每条都有案卷；欠缺一项——回放只执行
结构化 void，判读写的自由文本 void_if 不执行，红线 5 在
回放里是半执行。
- **简单基线**：结论「无优势可证」正是它的
价值——给所有 setup 立了必须越过的地板（≈0 期望）。
- **gold-book**：唯一 ground truth 资产，101 道、回归
护栏在位；涂字漏网 3 例为已知小疵。
- **预注册 + 全新底料纪律**：抓出自产自销底料靠的就是
它；方法论上是全系统最值钱的习惯。
- **执行轴**：盲考对齐阿布箭头 1/7，
系统性多等一根——与识别轴 7.5/8 并存，是「会认不会打」
的实测成绩（见对齐表 #2）。

### 采样层
- 随机点采样、账本触及采样：时刻与
doctrine 错位，v0.1/v0.3 已证。
- 要塞事件采样：对核心三族可用，对 G1 不对口。
- **确认窗采样**：G1 成形在两批全新标的上复现；
代价（入场位置变差）已由 H1 限价基点裁定对冲记账。

### trainer 人体系统（与自动线并行的一套）
- **预演制 + 两层计划 + 纪律轴**：与阿布「计划先行、
等式先算」同向；新批 4 笔 1 胜，执行失误（决胜点过期未
监控）说明人体执行仍是短板，与执行轴 1/7 同病。
- **自动线与人体线架构分岔**：预演制的战役层/段层在
自动判断层里不存在——judge 是单点决策，没有「局首冻结
地图」。两套系统共用 core 宪法，却不是同一个形状；哪套
是主线从未定版（打架 #4）。

## 打架清单（规则相悖对）

1. **路由 vs 分工**：菜单由数据标签先定，图读只能改定性
改不了菜单——被降格的层仍握着一半识别权。
2. **原则 #12 vs 限价默认化 vs H1 限价豁免**：#12 说 stop
优先（趋势语境），判读层默认限价（多在翻面语境），H1
刚给限价开了绿灯。三者其实可以调和（按语境分工），但
边界从未写明，现在是三份文件各说各的。
3. **2:1 设计目标 vs 1.5 地板锚定**：core 说 1.5 是地板
不是目标；判读实际贴着地板画目标（v0.5 三单的计划 RR
全在地板附近）；gate 只报 gap 不否决 = 默许锚定。RR
纪律有变成应试的风险。
4. **预演制 vs 机械采样**：G1 的 V3 要「预画决胜点」，采样器
是机械选点、判读员临场图读定 V3——自动线实际在跑临场制，
与人体线的预演制同名不同实。
5. **空仓合法 vs 测量需求**：见总判断。继续在历史段上加
消融轮次解决不了，破局点在前向影子（真实时间攒样本），
而它至今未开工。
6. **H6 阈值（n≥3）vs 回放纪律（n<30 不下结论）**：同一系统
两种统计标准，停牌比下结论还容易触发。
7. **attempts 双定义**：采样器到达快照 vs 判读决策根账本
（v0.5 VET 案：采样 0、判读三读未遂）——EP3 分层测的
不是判读员眼里的二次性。
8. **trend 标签三重身份**：已降格为附件，却仍是路由依据
与 H6 的 context 键——降格只降了一半。

## 处置建议（待用户裁定，本报告不自动执行）

修（方法明确、成本低）：
- 路由：趋势轨固定多带 B3 一张（候选主力不该靠冲突兜底
才进菜单）；或标签轨 + 账本轨取并集。
- H5：补 fortress/mm/pullback 三个根的置信检查。
- attempts：分层与判读统一用决策根账本值，采样快照只留档。
- trend_age.legs：修或删，不许恒定字段继续进提示。
- S1：在判据定版前，账面状态改标「未启用」，与 S2/S3 分开记。

裁（需要用户拍板）：
- H6 阈值：抬到样本 ≥8 且 0 胜，或先降为「只记观察不真
停牌」，与 n<30 纪律对齐后再恢复执法。
- 限价默认化：立语境分工——哪些语境许限价回踩、哪些必须
stop 触发（与 #12 的边界一次写清）。
- 分批出场：第一目标出一半、余仓跟序列目标——进不进
回放与 trainer 口径。
- 自动线定位：补战役层向预演制对齐，还是明确与 trainer
分家记账（自动线只做单点标注与测量）。
- 前向影子：开不开工（打架 #5 的唯一破局点）。

保留并倚重（A 档，不动）：眼/数据分工、红线 4、职责归位、
预注册 + 全新底料、gold-book、回放口径、简单基线、确认窗
采样、H1 双基点、H2。
