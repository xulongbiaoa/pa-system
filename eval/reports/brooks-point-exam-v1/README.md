# 阿布点位专项盲考 v1（2026-10-31）

新练习线：只考**点位判断**（全局认知基本功）——给定一页涂字后的阿布原册图，
判读员必须报出图上的决胜点位（价格、支撑/阻力、评级、锚种），对照标准是
阿布本人讲义原文（keys/）。与 gold-book 六批识别轴（语境/形态）口径不同，
本批只记点位轴。

## 采样规则（机械，抽前写死）

- 语料：`knowledge/brooks-cases/raw/*.jsonl` 全部页面记录（book=v<视频号>，
  slide=PDF 页号，已验与 mask 工具页号一致）。
- 排除：① 六批原册盲考用过的 103 页（KEYS.json–KEYS6.json ∪ gold-book
  items.jsonl，两者并集 103 页）；② slide ≤ 2（标题页）；③ 讲义文本
  < 200 字符（无足够对照内容）。
- 候选过滤（只看讲义文本元信息，不看图、不按难度挑）：
  关键词（不分大小写）命中至少一个：support / resistance /
  measured move / magnet / target；且文本中含至少 2 个互不相同的
  3–4 位价格数字 token（正则 `\d{3,4}(\.\d{1,2})?`）。
- 选取：候选按 (book 号, slide) 升序，等距取 12 页
  （index = round((i+0.5)×N/12), i=0..11）。
- 出题：`tools/book_exam_mask.py` 渲染涂字（dpi=100）。涂后墨迹校验：
  图区（高度 12%–95%）内暗像素（亮度 <128）占比 < 0.3% 的页作废，
  按候选顺序取下一页补位，作废数记入本文件与记分卡。
- 残余污染声明：排除集以 KEYS1–6 与 gold-book MANIFEST 能查到的为准；
  exec-exam 等其它批次若用过个别页未登记在此两处，存在残余污染风险；
  判读员继承协调者上下文的总污染声明同样有效。

## 判读契约（派出前冻结）

判读员每页只看涂字图（pages/<id>.png），输出 JSON：
```json
{"context": "一句话语境",
 "points": [{"price": 数字, "kind": "支撑|阻力",
             "rating": "要塞|据点|哨位",
             "anchors": ["锚种，如 波段高点/缺口锚/昨日高点/MM投影"],
             "why": "一句话依据"}],
 "key_point": "最关键点位的 price"}
```
价格读图上坐标轴（栅格数字未涂）。点数不限，但每点必须给得出锚种。

## 评分规则（派出前冻结，协调者对照 keys 执行）

- 阿布点名点位：key 原文中明确提到的价位或结构位（带价的支撑/阻力、
  MM 目标、昨日高低点、前高前低、缺口锚等），逐页由协调者摘成清单，
  记分卡逐页列明。
- 命中：判读员某点位与点名点位**结构同位**（同一结构身份，如同为
  昨日高点），或价格差 ≤ 该点名价位的 0.5%。
- 漏点：点名点位无判读员点位命中。虚点：判读员点位在 key 无对应、
  且图上结构身份不明；拿不准记「争议」，不算虚点。
- 页级评级：点名点位全中且无虚点 = 强命中；命中 ≥ 2/3 = 命中；
  ≥ 1/3 = 半中；其余 = 错。
- 总命中率 = Σ命中点数 / Σ阿布点名点数（全批汇总）。
- 增补 gold-book 只建议、不直接改（gold-book 冻结规矩）。
