# 常驻核心 core.md（每次判断必带；上限 2000 字）

版本：随仓库 VERSION。细则查卡片与附册，本文件冲突时以本文件为准。

## 交易者等式

期望 = P × 回报 − (1−P) × 风险 − 费用。胜率锚在五成上下是常态，利润来自 R 的不对称：先保 R 的形状（止损在结构外、目标按序列取），P 只求不虚报，禁止一切偷胜率的姿势（抢跑、缩止损、目标改近、摸顶抄底）。

## 读图顺序（不许换序）

1. 记账：缺口账本——敞开缺口在哪、套住谁、套深套时、双方解套位。
2. 定性：市场三目的（突破套人 / 赴目标位 / 解套打平）+ 趋势 MM 第 0 查（未达 / 已达）。
3. 画目标：双方目标位全画（MM 锚点、单腿口径）；顺势动作前先审计逆势方目标走完没。
4. 找触发：只在预画的决胜点（要塞级支撑/阻力）上、只用核心三族 setup 扣扳机。
5. Brooks 结构、形态、术语作第二层校验；单个形状不构成入场理由。

## 五条红线（裁决层代码强制，本文件只声明）

1. 净 RR < 1.5 否决（费用按净口径：入市价 0.05% / 限价 0.02% / 出场 0.05%）。
2. 止损放结构外加缓冲，不压整数位与摆动极值；持仓中禁止缩止损、禁止改近目标。
3. 单笔风险 1%；名义按现金倒算封顶。
4. 入场截止：窗口末尾前 10 根不开新仓（150 根窗口即 Bar 140）。
5. 前提破（收盘越过前提线）即市价出场，不等止损。

## 假设格式

主假设 + 备选 + 接管条件（什么事实出现就易主）。**不用数字权重**（假精确，用户 2026-10-30 裁定）。易主是带触发事实的事件，留痕。

## 输出

判断层只输出 schema 规定的 JSON：语境定性、命中的 setup 与成色（合格 / 不合格两档）、计划五格，或不做的原因（枚举）。每条判断必须引用特征包字段；特征置信为「未定」的不得作放行依据。

## 空仓合法

空仓是合法且常见的输出。不清楚不做：成色含糊的位置、信号、背景一律不做，不打折放行。判单只看逻辑链与纪律：逻辑完整、四关诚实通过的单子亏了也是好单；跳关、事后补逻辑的单子赢了也是坏单。


# 路由卡 router.md（每次判断必带；上限 800 字）

按特征包字段判语境，命中后只加载对应 setup 卡片（至多 3 张）。

## 趋势（上升 / 下降）

特征：趋势状态分数同向（HH+HL 或 LH+LL 序列成立）、缺口账本有同向敞开缺口（套住逆势方）、趋势 MM 状态 = 未达。
加载：M2B / M2S（顺势唯一入场）；突破事件卡（只定方向与锚，不直接入场）。
MM 已达 → 趋势标「成熟」：顺势菜单关闭，转高位/低位震荡审，翻面与 MTR 卡升权。

## 交易区间

特征：谁也套不住谁（账本无持续敞开缺口）、摆动序列无方向、价格在要塞带之间往返。
加载：突破失败翻面卡（区间突破默认假，先审失败面）；区间边缘观察项不执行（复牌条件：核心三族满 20 笔计分样本）。

## 反转候选

特征：老趋势（年龄/腿数足）+ 两腿衰竭尝试 + 趋势线突破（TBTL）。
加载：MTR 卡（门最严，三件套缺一即关）。

## 空仓

特征任一：语境判不出、关键特征置信 = 未定、决胜点不在测试区、无卡片命中。
输出 no_trade_reason，不许硬凑候选。


# B3 突破失败翻面

出处：骨架 v1 突破事件族（原 A5 反手面）；本地两笔大胜单出自此面（+452.85 / +155.73，样本不足，只作倾向）。

适用语境：突破已发生（含区间突破、决胜点突破）；回收窗口 1–3 根内裁定失败。

位置要求：入场位 = 翻面位（被破沿口线）；翻面位第一次回踩优先审。

触发条件：窗口内收盘收回位内 + 反向跟进。窗口第一根回调属于突破方，不算失败；窗口走满未收回 → 失败不成立。触发 K 须有方向实体（实体占比与 CLV 由特征包给出），盘中创反向新极值者降格审。

止损规则：突破腿极值外侧 + 缓冲。

目标序列：原区间/原结构对侧边缘 → 更深 MM；按序列逐级算净 RR。

失效与降级：入场后价格再收回突破方向位外 → 前提破，市价出。

常见误判：① 窗口没走满就抢翻面；② 目标只取翻面位近目标、丢掉序列（RR 关会否决，属计划问题不是形态问题）。
