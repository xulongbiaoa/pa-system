## 入场价可博弈（已修：取 A 案）

ds23（B3 做空，决策点收盘 11.43、止损 11.80、首目标 10.43），只动入场价：

| 入场价相对现价 | 承诺净RR | 裁决 | 实现 R | 出场 |
|---|---|---|---|---|
| +0.0% | 2.59 | pass | −1.031 | 止损 |
| +0.2% | 2.82 | pass | −1.034 | 止损 |
| +0.5% | 3.22 | pass | −1.037 | 止损 |
| +1.0% | 4.12 | pass | −1.046 | 止损 |
| +2.0% | 7.98 | pass | −1.083 | 止损 |

机制：做空入场价抬高 → 风险分母 `stop−entry` 变小 → 承诺 RR 涨 3.1 倍；但止损时 `R ≈ −1 − 费用/风险`，风险越小 |R| 越大。**提高承诺 RR 与降低实际亏损是反方向的**。直到 +5% 才被 H2 撞上（止损落进上方摆动高点之内）。

已按 **A 案** 落地（`gate/risk_rules.py`）：`rr_gate = min(rr(计划入场价), rr(现价))`，零新常数。市价单行为不变；限价单按现价保守计价，1.5 的含义变成「按现价可达」。金标准两个冻结计划（入场价都等于决策点收盘价）裁决不变。

**B 案（H7 入场价带宽）未采用**，记在此备查：`|entry/现价 − 1| ≤ k × seg_avg_range/现价` 只杀病态价、不惩罚正常回踩，但多一个常数 k，且 `seg_avg_range` 对小价标的（ds07 是 1.4e-5 量级）的稳定性未验。若将来 A 案的保守性伤到合法限价单，再回到 B 案。
